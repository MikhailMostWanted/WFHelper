# WantedFrame: CI и зависимости, preview.2

Продолжение ветки `feat/wantedframe-next`; исходная база из handoff сохранена. Рынок, формат снимка, pairing и серверные интеграции не заменялись.

## Исправления

- `sharp` и его платформенные пакеты обновлены до 0.35.5; Linux libvips — до 1.3.4. Override `adm-zip` обновлён до 0.6.1. ONNX runtime обновлён до 1.25.1 с исправлением очистки native metadata при завершении; модели сохранены. Windows OCR выполняется в отдельном utility process, с прежними Electron 41.10.4 и Windows binding 1.0.2. Родитель передаёт только изображение и язык и ждёт реального окончания работы и exit дочернего процесса. Текст сохранённого русского crop совпадает с предыдущим результатом полностью (101 символ); это replay кадра, не проверка текущей игры. [Исправление upstream](https://github.com/microsoft/onnxruntime/pull/27569).
- `pnpm audit --prod --audit-level high` проходит: в production зависимостях desktop приложения нет известных уязвимостей. `sprintf-js` 1.1.3 остаётся только в devDependencies через electron-builder, за пределами production цепочки ONNX. Отдельный существующий lockfile backend worker этим изменением не обновляется.
- При завершении приложение запрещает новые OCR inference, ждёт загрузку и уже начатые native вызовы, затем освобождает ONNX sessions до уничтожения Node. Проверка ненулевого exit сохранена.
- Выбор поля редактора оверлея отражается сразу; запоздавший ответ IPC не переключает панели управления на прежнее поле.
- Исправлены ширина основной области, положение панели поддержки, компактность мастерства и наведение на тонкие столбцы статистики. Свёрнутый sidebar имеет единую ширину 84 px в UI и хранилище.
- Удалены только неиспользуемые exports и строки переводов; используемые немецкие и китайские строки ChatGPT дополнены. UTF-8 сохранён. Намеренные `???` в названиях ещё неизвестных Разломов существовали в исходнике и не являются повреждённой кириллицей.
- E2E ожидания обновлены под принятый новый интерфейс: стартовая главная, Onest, нижние закреплённые настройки, ширина sidebar, размеры контролов. Ограничения переполнения, сохранения данных и exit code продолжают проверяться. Скриншотные эталоны просмотрены перед обновлением. На CI используются два Electron worker, чтобы не перегружать native OCR pools. Закрытие через Playwright сначала отключает inspector, затем запускает обычный quit; nonzero exit по-прежнему проваливает проверку.
- Workflow WantedFrame Next собирает preview.2 с версией интерфейса и provenance той же ревизии.

## Практическая регрессия

Локально проходят проверки раскладки Settings и статистики, редактора оверлеев, сохранения его полей после перезапуска и обоих вариантов закрытия с настоящим ONNX runtime: во время холодной загрузки и после inference. Backend regression проходит с его существующим lockfile. Полный сканер наград проходит с Windows, ONNX и комбинированным reader, включая нормальный exit. Английский корпус явно задаёт `en`: локальная русская настройка Warframe больше не подменяет указанный в тесте reader. Режим разбора отдельного пользовательского кадра сохраняет язык игры. Форсированное обновление «Мира» после главной теперь выполняется после уже начатого запроса, а не теряется. E2E fixtures устанавливаются до первого запроса данных; проверка выбора artwork использует доступное fixture image, не внешний CDN.

Синтетические пустые pixels проверяют только жизненный цикл ONNX, а не качество распознавания в игре. Предыдущие ограничения игровых кадров, fullscreen и нескольких мониторов остаются в `WANTED_DESIGN_VERIFICATION.md`. Реальные сделки и изменение ордеров эта регрессия не выполняет.

Windows-пакет preview.2 должен содержать точную ревизию в `build-info.json` и `source-revision.txt`. Факт установки, контрольные суммы и практическая отправка фиксируются отдельно в локальных артефактах сборки; секреты и pairing в публикацию не включаются. Authenticode подпись не добавляется этим изменением.
