# WantedFrame: передача данных и дальнейшая персонализация

Ветка: `feat/wantedframe-next`, база перед этим этапом `9a5cfb3` (0.2.0-preview.1).
Задача владельца: максимально полные данные Warframe по запросу в ChatGPT, а визуал и персонализацию
доработать отдельно в Codex. Не заменять работающий рынок, не создавать новый проект с нуля.

## Уже реализовано в исходниках

- Новый разрешённый комплект `wantedframe.account.v1`, 51 зарегистрированный раздел со схемами:
  `services/accountBridge.ts` и `integrations/wantedframe_mcp/schema.json`.
- Инвентарь, экземпляры, моды/ранги/конфигурации, мистификаторы, осколки, loadouts, исторический XP,
  Кузница, дополнительные категории, репутация, навыки, лимиты, счётчики, привязанный кеш профиля,
  существующий справочник рецептов/компонентов/дропов. Подробности — в карте возможностей, не в памяти чата.
- ZIP для обычного чата: `account.json` и `README_CHATGPT.md`. Современная сборка использует это вместо
  прежнего одиночного `account-snapshot.json`; старый локальный файл остаётся для совместимости.
- Подключение своего сервера, подтверждённая ручная отправка, отдельно включаемая автосинхронизация
  изменений с ограничением частоты. Подключение шифруется хранилищем ОС. Автосинхронизация не работает
  с неподтверждённым manual-импортом; нельзя автоматически соединять профили разных аккаунтов.
- Python MCP с OAuth только для владельца: каталог, поиск, выборочное чтение, глубокие поля сборок,
  рецепты, ревизии/страницы, изменения двух снимков и независимое публичное мировое состояние.
- Девять инструментов с русскими описаниями и инструкциями выбора. Пользователю не нужно помнить их имена.
- На сервере только два снимка; нет архива всего аккаунта за годы, нет массовой синхронизации скриншотов,
  нет новых способов чтения памяти игры и нет платных API моделей.

## Что сделать в Codex

1. Взять эту ветку и фактический последний коммит; не откатываться на старый main. Сохранить профиль
   установленного WantedFrame перед обновлением. Не потерять рыночную сессию и настройки.
2. Развернуть ТОЛЬКО `./integrations` на MAIN согласно `integrations/README.md`, на отдельном hostname/порте.
   Подключить существующий HTTPS-прокси. Не менять работающие TGPT, Infra Control или MAX. Не запрашивать
   игровой пароль. Нужны OAuth App, домен и один приватный pairing-файл; пользователь импортирует его в GUI.
3. Пройти реальный цикл: инвентарь → комплект → отправка → OAuth ChatGPT → карта данных → один ресурс,
   одно оружие `/configs/0/mods`, одна запись производства → повторная отправка после изменения инвентаря.
   Сверить числа с игрой. При неизвестной привязке не «починять» это снятием проверки: изучить поддержку
   источника и согласовать нормальное связывание либо оставить ручной импорт.
4. Проверить `unmappedCollections`, `omittedFields`, поля с null на реальном снимке. Расширять разрешённую
   схему только по доказанным игровым полям, не добавлять «отправить весь сырой JSON». Никогда не делать
   неизвестный ранг/количество нулём. Каждая дополнительная категория должна иметь дату и покрытие.
5. Сохранить механизм передачи при визуальной переработке. Системное меню передачи — временный простой
   интерфейс; его можно заменить полноценным разделом «ChatGPT»: статус, объём, источники, пробелы,
   отправить сейчас, автоматический режим, экспорт, отключение. Не требовать знания API/MCP-инструментов.
6. Визуал: компактные пассивные оверлеи без захвата мыши/перекрытия наград, персонализация под владельца,
   отзывчивый старт. OCR доводить на реальных кадрах и коротком кольцевом журнале, без участия владельца
   во время выбора награды. Эта итерация не переписывает OCR заново.

## Не выдать за готовое

Сервер ещё не установлен на MAIN и не добавлен в ChatGPT этим изменением. Тестовые снимки синтетические.
Нет доказательства реальной полноты каждого поля конкретного аккаунта; нет полного калькулятора урона,
живого списка активных модификаторов боя или гарантии, что выбранный пресет активен сейчас.
У game.items дата актуальности неизвестна: нельзя называть его текущим патчем без обновления/проверки.
Для онлайн-цен продолжает работать существующий рынок приложения; MCP не получил отдельного API ордеров.

Проверки под реальные риски: один живой цикл плюс релевантная регрессия. Не строить бесконечную тестовую
кампанию и не заменять пользовательский результат количеством тестов. Итог: готовая сборка и конкретно
что подключено, что проверено, чего источник не отдаёт.
