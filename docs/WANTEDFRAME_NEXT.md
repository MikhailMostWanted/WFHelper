# WantedFrame Next — preview

Отдельная ветка `feat/wantedframe-next`, без замены релиза 0.1.0 и без массового слияния upstream.

## Изменения

- Создание окна до тяжёлого наполнения справочника; поэтапная подготовка с уступкой циклу событий. Ранние запросы ждут готовности, а не получают пустую базу.
- Русский распознаватель характеристик модов Разлома. Английская модель не требуется для этой ветки. Словарь собран из пар исходных строк DE в репозитории.
- Очередь OCR ограничивает фактически выполняющиеся операции: таймаут не считается остановкой нативного кода. Английский fallback после русского таймаута убран. Неоднозначные названия компонентов не угадываются.
- Компактный пассивный вид оверлеев. Подробности возвращаются клавишей взаимодействия. Редактор сохраняет исходные координаты. Прозрачное окно остаётся click-through: уменьшена видимая панель, не изменён захват игры.
- Последний локальный `account-snapshot.json`: количества, экземпляры снаряжения, конфигурации и ссылки на моды, известные ранги, осколки, исторический XP отдельно от владения, пресеты и исходные числовые данные модов Разлома. В настройках — покрытие данных и экспорт JSON.

## Границы

Это preview. Снимок отражает только доступные выбранному источнику поля. Источник не заменяется; новые методы чтения памяти игры не включаются. Отсутствующее поле — `null`, не ноль. Время получения инвентаря отдельно от времени экспорта. `rawValue` в fingerprint — исходное кодирование броска, **не проценты характеристики**. Полный игровой калькулятор и серверная синхронизация не заявляются готовыми в этой части изменений.

Проверки без игры покрывают форматы, отсутствие переноса произвольных полей авторизации, очереди, разбор русских характеристик, сохранение английской ветки и сборку. Скорость и точность на реальном Windows-ПК измеряются на пользовательских кадрах. Windows CI без русского языкового пакета не доказывает качество нативного OCR.

Перед preview сохранить копию пользовательского профиля WantedFrame. Источники инвентаря, рыночная сессия и цены остаются прежними. Установщик preview не является автоматическим обновлением стабильного выпуска.
